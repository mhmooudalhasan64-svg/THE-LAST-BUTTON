# THE LAST BUTTON

**One button. A thousand secrets.**

A mysterious, minimalist casual puzzle game built with React, TypeScript, and Vite.

## Current MVP

- Atmospheric single-button interaction
- Mystery messages, clues, and rare anomalies
- Chapter and level progression
- Clue archive
- Achievement tracking
- Local autosave (no account required)
- English and Arabic interface toggle
- Optional generated sound feedback
- Responsive desktop and mobile layout

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Tech stack

- React + TypeScript
- Vite
- Lucide icons
- CSS responsive interface
- Browser localStorage

## Roadmap

1. Refine mystery pacing and narrative chapters.
2. Add authored clue chains and multiple endings.
3. Add sound design and accessibility polish.
4. Package the web app for Android with Capacitor.

Progress is stored locally in the current browser. No account or backend is required for this MVP.
